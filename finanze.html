⚠ Prima configurazione — crea la tabella su Supabase

La tabella finanze non esiste ancora. Incolla questo SQL nell'editor di Supabase (SQL Editor → New query) e poi ricarica la pagina:

create table if not exists finanze ( id uuid default gen_random_uuid() primary key, anno integer not null, mese integer not null, tipo text not null check (tipo in ('uscita','entrata','risparmio')), nome text not null, importo numeric(10,2) not null, nota text, target numeric(10,2), created_at timestamptz default now() ); alter table finanze enable row level security; create policy "accesso totale" on finanze for all to authenticated using (true) with check (true);
⚠ Spese anticipate — serve una query su Supabase

Nel progetto Supabase dello spazio → SQL Editor, poi ricarica:

alter table finanze add column if not exists pagato_da text; alter table finanze add column if not exists rimborsato boolean default false; alter table finanze add column if not exists rimborsato_il timestamptz;

alter table finanze add column if not exists periodo_dal date; alter table finanze add column if not exists periodo_al date; create table if not exists partecipanti ( id uuid default gen_random_uuid() primary key, nome text not null, attivo boolean default true, created_at timestamptz default now() ); create table if not exists quote_bollette ( id uuid default gen_random_uuid() primary key, finanze_id uuid not null references finanze(id) on delete cascade, tipo text not null check (tipo in ('persona','evento')), nome text not null, partecipante_id uuid references partecipanti(id), evento_id bigint, importo numeric(10,2) not null, pagato boolean default false, pagato_il timestamptz, entrata_id uuid, created_at timestamptz default now() ); alter table partecipanti enable row level security; alter table quote_bollette enable row level security; create policy "accesso totale" on partecipanti for all to authenticated using (true) with check (true); create policy "accesso totale" on quote_bollette for all to authenticated using (true) with check (true); insert into partecipanti (nome) values ('Stefano'),('Michela'),('Cinus'),('Alejandra');
